The engine, rules, CI/CD pipeline, LLM triage layer, and lab setup guide.

Detection rules are code — they deserve version control, code review, tests, and CI/CD. This project is a small, complete demonstration: a pure-Python Sigma engine unit-tests each detection against known-malicious and benign events with no live SIEM, a GitHub Actions pipeline gates every change, and an LLM layer (Groq) drafts the tier-1 triage an analyst would otherwise write from scratch.

  • Offline Sigma evaluation engine (parser + matcher)
  • Every rule ships with true/false-positive tests
  • CI: lint → validate → test → translate → deploy
  • Compiles rules to Splunk SPL / Elastic queries
  • ATT&CK Navigator coverage layer
  • LLM alert triage with prompt-injection defense
