Active Directory Database Dump via ntdsutil
proc_creation_ntdsutil_dump		Credential AccessT1003.003high4✔ PASS

Detects use of ntdsutil to create an Install-From-Media (IFM) copy of the NTDS.dit Active Directory database. On a domain controller this hands an attacker every domain credential hash at once, making it one of the highest impact credential-access actions. Legitimate use is limited to DC promotion and planned backups.

False positives:
  • Sanctioned domain-controller backups or DC promotion. Confirm the operation was change-managed and initiated by an administrator.
Active Directory Reconnaissance via Built-in Tools
proc_creation_ad_recon		DiscoveryT1087.002, T1482medium4✔ PASS

Detects domain reconnaissance performed with living-off-the-land tools: net group/user queries against the domain, nltest trust and DC enumeration, and dsquery. This activity typically follows initial access as an operator maps privileged accounts and domain trusts before moving laterally. Local (non- domain) net queries are excluded to keep the signal high.

False positives:
  • Administrators and directory tools legitimately query AD. Volume and sequence (many discovery commands from one host in minutes) are the real signal; correlate rather than alert on a single benign query.
Ingress Tool Transfer via certutil
proc_creation_certutil_download		Command And ControlT1105high4✔ PASS

Detects certutil.exe being abused to download a remote file (urlcache / verifyctl with an http/https/ftp URL). certutil is a signed certificate utility, not a downloader, so this pattern is a classic LOLBIN ingress-tool-transfer used to stage second-stage tooling while evading application allow-listing.

False positives:
  • certutil can legitimately fetch CRLs. The combination of urlcache + an arbitrary http URL writing a local file is the distinguishing factor.
LSASS Memory Dump for Credential Theft
proc_creation_lsass_dump		Credential AccessT1003.001high4✔ PASS

Detects attempts to dump the memory of LSASS, the process that holds cached credentials and secrets. Covers two of the most common techniques: ProcDump with the -ma (full dump) flag against lsass, and the built-in comsvcs.dll MiniDump export invoked through rundll32. A successful LSASS dump typically precedes credential reuse and lateral movement.

False positives:
  • Legitimate crash-dump collection by monitoring agents. Verify the parent process and the destination path of the dump file.
Local Account Creation or Privileged Group Addition via net
proc_creation_local_account_manipulation		PersistenceT1136.001, T1098medium4✔ PASS

Detects creation of a new local account (net user /add) or the addition of an account to the local Administrators group (net localgroup administrators /add). Attackers create backdoor accounts for durable access and add accounts to privileged groups to escalate; both are cheap, high-signal actions on servers and workstations that rarely see routine local-account churn.

False positives:
  • Provisioning scripts and MDM tooling create local accounts. Correlate with the account name and whether the action was operator-initiated.
Microsoft Defender Tampering
proc_creation_disable_defender		Defense EvasionT1562.001high5✔ PASS

Detects attempts to weaken Microsoft Defender: disabling real-time/behavior monitoring via Set-MpPreference, stopping the WinDefend service, or adding a broad ExclusionPath so future payloads are ignored. Disabling endpoint protection is a common precursor to dropping tooling and is high-signal outside of sanctioned maintenance windows.

False positives:
  • Endpoint software or IT maintenance may set exclusions. Confirm the change was authorized and scoped narrowly (a specific signed path, not a whole drive).
Mshta Executing Remote or Inline Script
proc_creation_mshta_remote		Defense EvasionT1218.005high4✔ PASS

Detects mshta.exe (a signed Microsoft binary) being used to proxy execution of a remote payload (http/https) or inline script (javascript:/vbscript:). This is a well-worn signed-binary-proxy-execution technique that lets attackers run code while blending in with a trusted system binary. Local .hta launches from trusted directories are intentionally out of scope to limit noise.

False positives:
  • Legacy line-of-business HTA applications hosted internally. Allow-list the specific URL or file path if the app is known-good.
Office Application Spawning a Command Interpreter
proc_creation_office_spawns_shell		ExecutionT1059high4✔ PASS

Detects a Microsoft Office application (Word, Excel, PowerPoint, Outlook) spawning a command interpreter or script host. This parent/child relationship is a high-fidelity indicator of malicious macro or phishing-document execution, since Office apps rarely have a legitimate reason to launch cmd, PowerShell, wscript, cscript, or mshta.

False positives:
  • Rare legitimate add-ins or document automation. Investigate the child command line; a benign add-in launching a signed helper is distinguishable from a macro dropping a downloader.
PowerShell EncodedCommand Execution
proc_creation_powershell_encoded		ExecutionT1059.001high4✔ PASS

Detects PowerShell (powershell.exe / pwsh.exe) invoked with an encoded-command flag (-EncodedCommand / -enc / -ec). Attackers use Base64-encoded payloads to hide script contents from casual log inspection and to sidestep naive string detections. Matching on OriginalFileName as well as Image also catches the binary being renamed to evade image-name detections.

False positives:
  • Some legitimate remote-management and deployment tools pass encoded commands. Tune by allow-listing known parent processes or signed script hosts.
Process Execution via WMIC process call create
proc_creation_wmic_process_call_create		ExecutionT1047medium4✔ PASS

Detects use of WMIC to spawn a new process via "process call create". This is a common living-off-the-land execution and lateral-movement technique because it runs the child process under WmiPrvSE, breaking the normal parent/child chain and evading detections that pivot on process ancestry.

False positives:
  • Legitimate software deployment or administrative scripts. Tune by allow-listing the specific remote hosts / accounts used by your management tooling.
Sensitive Registry Hive Export via reg save
proc_creation_reg_save_hive		Credential AccessT1003.002high4✔ PASS

Detects use of reg.exe to save the SAM, SYSTEM, or SECURITY registry hives to disk. Together these hives allow offline extraction of local account password hashes and LSA secrets, so exporting them is a classic credential-access step. Backing up non-sensitive keys is common and is deliberately excluded.

False positives:
  • Backup software that legitimately exports the SYSTEM hive. Correlate with the running account and whether SAM/SECURITY are dumped in the same window.
Shadow Copy Deletion / Recovery Inhibition
proc_creation_shadowcopy_delete		ImpactT1490critical4✔ PASS

Detects deletion of Volume Shadow Copies and tampering with Windows recovery, via vssadmin, wmic shadowcopy, wbadmin, or bcdedit. This is the near-universal pre-encryption step in ransomware playbooks: destroying backups and disabling recovery so victims cannot roll back. Very high fidelity and time-critical.

False positives:
  • Rare. Some backup products prune shadow copies; these are known and scheduled. Any interactive vssadmin delete on a workstation warrants immediate triage.
Suspicious Autorun Value in Registry Run Key
registry_run_key_suspicious		PersistenceT1547.001high4✔ PASS

Detects a value written to a CurrentVersion\Run or \RunOnce autostart key whose data points at a script host, LOLBIN, or a user-writable staging directory (AppData/Temp/ProgramData). Legitimate applications register autoruns too, so the detection keys on the *content* of the value rather than merely the location.

False positives:
  • Some legitimate updaters stage helpers in ProgramData. Confirm the writing process (Image) and whether the target binary is signed.
Suspicious Scheduled Task Creation via schtasks
proc_creation_scheduled_task_create		PersistenceT1053.005medium4✔ PASS

Detects creation of a scheduled task (schtasks /create) whose action runs a script interpreter, an encoded command, a binary staged in a user-writable directory, or runs as SYSTEM. Scheduled tasks are a durable persistence and privilege-escalation mechanism; keying on the action's content suppresses the large volume of benign task creation.

False positives:
  • Software installers create tasks that call helpers in ProgramData. Confirm the task action binary is signed and expected.
